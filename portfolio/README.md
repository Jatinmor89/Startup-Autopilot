# 🚀 Jatin Mor - Portfolio Website

A stunning animated portfolio website showcasing my Full Stack Web Development projects.

## ✨ Features
- Animated hero with typing effect
- Glowing orb backgrounds
- Scroll reveal animations
- Skill bars with animations
- All 6 projects showcased
- Dark theme with purple/pink gradients
- Fully responsive

## 🛠️ Tech Used
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Space Grotesk + Fira Code)

## 🚀 Deploy to GitHub Pages

1. Create repo named `portfolio` on GitHub
2. Push all files
3. Go to Settings → Pages → Deploy from main branch
4. Live at: `https://jatinmor89.github.io/portfolio`

## 📁 Files
- `index.html` - Main HTML
- `style.css` - All styles + animations
- `script.js` - Typing effect, scroll animations
